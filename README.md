# Trumpeters Missionary Institution

A mobile-first ministry website built with React, Vite, Tailwind CSS, and React Router.

## Run locally

```sh
npm install
npm run dev
```

Create and preview a production build:

```sh
npm run build
npm run preview
```

## Pages

- Home
- About and frequently asked questions
- Get involved and volunteer enquiry
- Learn and grow
- Events and health expo information
- Community and prayer
- Give and partner
- Members
- Contact
- Privacy and safety

Volunteer enquiries and contact links open WhatsApp; they are not stored or submitted to a website backend. Secure payment processing, member authentication, live event updates, and regional group invitations require services and details from the ministry before they can be enabled.

The Cross Roads health expo flyer and its team-photo crop were provided by the ministry. Other website imagery is used as illustrative stock photography; replace it with approved ministry photos as they become available.
